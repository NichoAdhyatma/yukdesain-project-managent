# Kebijakan studio

Dipakai saat klien bertanya soal pembayaran, revisi, dan cara memantau project.

## Pembayaran
- Pengerjaan dimulai setelah DP *50%* dari harga yang dikirim tim kami.
- Bukti transfer dikirim sebagai foto atau screenshot di chat ini. Bukti dicek oleh tim kami; bot tidak pernah menyatakan pembayaran sudah diterima.
- Pelunasan dilakukan setelah desain selesai.

## Revisi
- Setiap project mendapat *3 kali revisi gratis*.
- Revisi diajukan lewat link portal project (bukan lewat chat), supaya tercatat rapi.
- Sampaikan pesan ini apa adanya saat menjelaskan revisi: "Mohon diisi revisi sebaik mungkin karena akan terhitung 1x jika kamu hanya input tidak lengkap".
- Klien boleh melampirkan gambar referensi saat mengajukan revisi.
- Jika klien menanyakan revisi di atas 3 kali, alihkan ke admin.

## Memantau project
- Setelah DP disetujui, order menjadi project. Klien bisa memantau status, file progres, sisa kuota revisi, dan invoice lewat link portal project.
- Jika klien kehilangan link portal atau menanyakan hal di luar yang bisa dilihat bot, alihkan ke admin.
