# Audit antislop 009: halaman progres klien (portal tokenized), hukum UX dan responsif (2026-11-13)

Mode: AUDIT (sesudah jadi). Belum ada yang diubah; perbaikan hanya untuk nomor yang disetujui.

Cakupan: `src/app/client/[token]/page.tsx`, tampilan tracking setelah brief dikirim (hero, kartu ringkas, timeline,
tab Brief/Invoice/Pembayaran, revisi/approve, file final).
Cara periksa: project uji lokal (Poster Menu, progres 60%, DP 50%, ada catatan tambahan klien) di 375×812 (HP),
768×1024 (tablet), 1366×900 (desktop), ditambah pengukuran DOM (target sentuh, ukuran teks, teks terpotong, heading).
Acuan: hukum UX (Hick, Fitts, Jakob, Miller, Tesler, Doherty, Zeigarnik, goal-gradient, serial position, peak-end,
proximity), UI/UX Pro Max §1–§8, antislop C-1–C-5.

Yang sudah baik: tidak ada gulir horizontal halaman di 375px; semua tombol ikon berlabel; batang progres 60% di hero
(goal-gradient); badge status jelas; kartu file final terkunci (audit 008) memakai pola yang benar.

temuan.
