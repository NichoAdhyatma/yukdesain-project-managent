### F-04 — R-03 (Quality Locks) | Cart Sides table — horizontal scroll on mobile | **FIXED**

**File:** line 717

Changed from a single forced-scroll table to a responsive dual-view layout:
- **Mobile (`< 640px`):** Stacked cards — each row becomes a card with side name, dimensions, and brief description stacked vertically. No horizontal scroll.
- **Desktop (`sm:` and up):** Original table preserved with `overflow-auto` for the full data view.

```tsx
{/* Mobile: stacked cards */}
<div className="sm:hidden space-y-2">
  {cartSides.map((side, idx) => (
    <div key={idx} className="rounded-lg border bg-card p-3 space-y-1.5">
      <div className="flex items-baseline justify-between gap-2">
        <p className="text-sm font-semibold">{side.sideName}</p>
        <p className="text-xs text-muted-foreground">{side.dimensions}</p>
      </div>
      {side.textBrief && <p className="text-xs text-muted-foreground">{side.textBrief}</p>}
    </div>
  ))}
</div>
{/* Desktop: table */}
<div className="hidden sm:block overflow-auto">...</div>
```
