# Anti-Slop Audit 003: Dashboard mobile navigation
**Date:** 2026-11-01
**Files:** `src/app/(dashboard)/client-layout.tsx`, `src/components/layout/sidebar.tsx`, `src/components/layout/global-refresh-button.tsx`

Design Read: operational admin dashboard for studio staff on phones, existing YukDesain sidebar language, dial ENERGY 1 / RHYTHM 1 / MOTION 1 (navigation chrome, not a showcase).

## Problem

Below `md` the 256px sidebar stayed open and left ~119px for page content at 375px.

## Change

- Below `md` the persistent `aside` is hidden; a 44px menu button in the page top bar opens the same sidebar inside the existing `Sheet` (left side, 288px, max 85vw).
- Menu still comes from `menu_items` + `menu2roles` via the layout; nothing hardcoded.
- Desktop (`md`+) keeps the collapsible aside unchanged.

## Gate

| Rule | Status | Evidence |
|------|--------|----------|
| R-02 | PASS | No em dash in new UI text ("Open menu", "Close menu", "Navigation menu") |
| R-03 | PASS | 375px: document and content scrollWidth = 375 on /dashboard, /form-link, /projects, /designers, /services, /media, /invoices, /financial, /settings, /activity-history, /designer. Drawer links, logo, close, user trigger, role toggles, logout and refresh are all >= 44px tall |
| R-24 / R-26 | PASS | Menu button opens drawer; X and Escape close it; tapping a link navigates and closes it; user menu opens above the drawer |
| R-32 | PASS | Escape closes, focus returns to "Open menu"; links carry `aria-current="page"` |
| R-35 | PASS | Click-through at 375 / 768 / 1440 in a running dev server. Drawer auto-closes when the viewport grows past `md`; desktop collapse/expand still 256 <-> 64px |
| R-06 | PASS (reason) | Drawer group labels reuse the existing 11px uppercase sidebar label style so both navs read as one component |
| R-04 | PASS (reason) | `Menu` / `X` glyphs are the conventional open/close affordance, from the icon set already used in the sidebar |
| R-10 | PASS | Only the shared Sheet overlay blurs, unchanged |

## Out of scope (noted, not changed)

- `/settings` tab list overlaps its labels at 375px (page-level tabs, being reworked on the WhatsApp settings branch).
- `/projects` table scrolls horizontally inside its own card at 375px (contained, no page overflow).
