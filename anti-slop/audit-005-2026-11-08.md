Tidak ada temuan Hard Gate: tanpa em dash di teks baru, tanpa angka atau klaim karangan (persen progres berasal dari
`ProjectUpdate.progress`), semua kontrol punya aksi nyata, state memuat (skeleton), kosong, dan galat (dengan Coba lagi) ada.
Kontras diukur di browser: teks muted 4.74:1, label revisi menunggu 5.03:1, "Lewat deadline" 4.78:1, angka di chip filter ≥5.11:1.

Click-through (R-35), dev server worktree port 3101, akun seed desainer, data uji lokal:
- Kartu project → detail terbuka, URL `?project=`; "Semua project" → kembali ke daftar; Back browser → kembali ke detail.
- Filter Selesai → "Tidak ada project yang cocok"; Hapus filter → 2 project; cari "0002" → 1 project.
- Kirim update dengan catatan kosong → fokus ke catatan + pesan galat; preset 50% lalu ketik 60 + catatan → banner sukses, toast, riwayat 60%.
- Kosongkan → input kosong; API: tanpa persen 201, persen 150 → 400, dua lampiran → 400, lampiran milik lain → 400, satu lampiran → 201, lampiran dipakai ulang → 400.
- Uploader: file .txt → pesan galat di dekat field (bukan `alert()`).
- Status Selesai → badge Selesai, lalu Sedang Dikerjakan → badge kembali.
- Kirim hasil akhir → dialog terbuka, fokus di dalam, tombol kirim nonaktif saat catatan kosong, Escape menutup, fokus kembali ke tombol.
- Viewer: Enter pada thumbnail → viewer terbuka di gambar yang benar; panah kanan → gambar berikutnya; Putar ke kanan → rotate 90°;
  Tab berputar di dalam viewer; Escape menutup dan fokus kembali ke thumbnail. Brief: 4 gambar (logo + 3 referensi) dalam satu viewer.
- 375px: lebar dokumen 375, tidak ada elemen yang melewati viewport, semua tombol/input/tab di daftar dan detail ≥44px.

Alasan keputusan (R-31):
- Master-detail (daftar kiri, detail kanan; satu layar di HP): desainer berpindah antarproject tanpa menutup modal bertumpuk, dan
  viewer.js tidak perlu hidup di dalam dialog (fokus dan Escape tidak berebut).
- Form progres di tab pertama dan paling atas: itu tugas paling sering; status dan hasil akhir di bawahnya.
- Motif identitas: bilah progres yang sama di kartu daftar, ringkasan detail, dan tiap entri riwayat.
- Satu aksen: warna `primary` hanya untuk bilah progres, tombol terpilih, dan tombol Kirim update.
- Ikon: CalendarClock (deadline), Eye (catatan tampil ke klien), Send (kirim), FileText (file non-gambar), Loader2 (proses).
- Backdrop viewer 82% hitam: gambar desain perlu latar gelap yang tidak bersaing dengan halaman di belakangnya.
